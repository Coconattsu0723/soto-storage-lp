## 4. 変更管理ルール

- 新しい決定や変更は、該当する正本Markdownと本ログの両方へ反映する。
- 旧案を削除して見えなくするだけでなく、重要な変更は「Rejected / Previous Idea」とともに残す。
- 数値、料金、補償、対応エリア、コピーを変更する場合は、使用箇所を横断して整合性を確認する。
- 未確定事項は「要確認」のまま保持し、AI側で正式決定へ変えない。
- 新規素材が必要に見えても、ユーザー確認前に追加制作しない。
